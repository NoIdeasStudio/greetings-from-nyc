# Greetings from NYC

Static Webflow export of the Sackville & Co. **Greetings from NYC** page.

## Run locally

From this folder:

```bash
python3 -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000).

Any other static server works too, for example `npx serve`. Open `index.html` directly in a browser if you only need a quick look; videos and some assets behave more reliably over HTTP.
